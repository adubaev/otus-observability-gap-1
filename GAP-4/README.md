# Домашнее задание 4

Дашборды в Grafana.

## Что сделал

Для этой работы использовал сервер из предыдущих ДЗ. Установил Grafana 13.2.3 в Docker Compose и подключил к Prometheus.

Создал две папки:

- `infra` — дашборд «OTUS — Инфраструктура»: загрузка CPU, использование RAM, заполнение корневого раздела и сетевой трафик;
- `app` — дашборд «OTUS — WordPress»: доступность сайта, nginx, PHP-FPM и MariaDB, время HTTP-проверки сайта.

## Задания со звёздочкой

В Grafana создал два правила с отправкой уведомлений в Telegram:

- `OTUSNodeExporterDown` — уровень `warning`, если недоступен сборщик метрик сервера;
- `OTUSWordPressUnavailable` — уровень `critical`, если проверка WordPress не проходит.

Правила проверяются каждые 30 секунд. Перед срабатыванием проблема должна сохраняться одну минуту. Проверял алерты остановкой контейнеров node-exporter и WordPress. Сообщения о проблемах пришли в Telegram, после тестов сервисы запустил обратно.

Также сделал DrillDown. В общем дашборде есть таблица серверов. При нажатии на адрес открывается «OTUS — Сервер подробно». В него передаются выбранный `instance` и период времени. Кроме основных метрик, там показываются загрузка CPU по ядрам и память в GiB.

## Дополнительно

Настроил [Grafana на своём домене](https://grafana.adubaev.ru) по HTTPS. Получил сертификат Let's Encrypt и проверил его автоматическое продление.
